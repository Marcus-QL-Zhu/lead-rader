# Lead Radar 到人工审批申请的流程

```mermaid
flowchart TD
    A["05:00 定时任务<br/>或用户主动发起"] --> B["读取固定可信信源"]
    B --> C["抓取、标准化、去重与事件聚簇"]
    C --> D["识别早期招聘信号"]
    D --> E["证据计分并生成 Top 20 公司"]
    E --> F["对 Top 20 做基础研究"]
    F --> G["JOSINT<br/>公开招聘广告仅作晚期验证"]
    F --> H["Metaso<br/>仅对重点项目做全网补充核验"]
    F --> I["Evidence Compiler<br/>逐家公司整理可引用事实包"]
    G --> I
    H --> I
    I --> J["MiniMax 单公司分析<br/>阶段变化 → 能力缺口 → Director+ 岗位"]
    J --> K{"岗位引用真实 evidence_id？"}
    K -- "否" --> X["记录失败并在飞书汇报原因<br/>不沿用旧草稿"]
    K -- "证据不足" --> W["保留公司与 watch_for<br/>不虚构职位"]
    K -- "是" --> L["按具体能力聚簇人才主题<br/>保留来源岗位 ID"]
    L --> M0["MiniMax 单主题生成<br/>一条匿名职位广告 JSON"]
    M0 --> M{"主题级确定性闸门<br/>标题与主题一致、主题自己的关键词、单城市、<br/>Liepin Schema、匿名、同批不重复"}
    M -- "否" --> N["仅调用一次有界修复"]
    N --> O{"修复后再次通过校验？"}
    O -- "否" --> X
    M -- "是" --> P["保存草稿包<br/>SQLite 状态 = pending_approval"]
    O -- "是" --> P
    P --> Q["将 Top 20 线索摘要与职位草稿<br/>合并为一条飞书汇报"]
    Q --> R["向用户申请人工审批发布职位"]
    R --> S(["流程在此停止<br/>未经批准不得调用猎聘发布"])
```

## 边界

- 每日任务只做 Top 20 基础研究；深度研究和 float 分析由用户主动触发。
- MiniMax 按公司独立推测组织缺口，再按人才主题独立生成职位广告；模型和凭证从 OpenClaw 配置读取。
- 证据不足的公司仍保留在 Top 20，但只输出 watch_for，不为了职位数量制造岗位。
- 确定性校验阻止宽泛职位、多城市、企业身份泄露或不符合猎聘字段契约的草稿进入审批。
- 本流程只到“申请人工审批”为止；猎聘发布属于审批后的独立执行阶段。
