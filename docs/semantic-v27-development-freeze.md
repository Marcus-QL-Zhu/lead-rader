## 冻结后的 V27 合同

1. 宿主预建 Article Entity Ledger，MiniMax 只能选择实体 ID。
2. 宿主预建不可变 Action Span 与 Atomic Claim，每批最多 3 条。
3. MiniMax 只做接受/拒绝、主体选择、状态与有限字段提取；事件类型、引文和 ID 由宿主锁定。
4. 历史/能力/总结性叙事、图片署名、roadmap 弱主体在模型调用前剔除。
5. 同 Span 的容量与技术重复、投资与订单重复由确定性规则消解；不同独立动作不合并。
6. 每个 Claim 必须进入 accepted/rejected/failed 之一；验收要求 failed=0、strict-ready=全部文章。
