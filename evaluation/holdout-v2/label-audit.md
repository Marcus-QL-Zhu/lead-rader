# Uniform future-job label audit

A separate label agent was denied access to local predictions and searched all
ten candidates with the same query matrix: company name plus
Director/Head/VP/总监 and each month in April-June 2026; official careers
sites; and LinkedIn, Liepin, Zhaopin and BOSS indexes. It required an explicit
Director+ title and an exact machine-verifiable publication date in
`[2026-04-01, 2026-07-01)`.

No qualifying Director+ job was observed for any candidate. Relative dates
such as “2 months ago”, cutoff-preceding roles, July roles, and titles such as
主任工程师/Manager/Program Lead were excluded. This empty label set is retained
as an honest control result rather than being backfilled from weaker evidence.
