# Strict holdout v12

This is a fresh foreign-company operational-event holdout. Twelve companies
were selected from commissioned factories, integrated R&D centers, regional
headquarters and live customer infrastructure. Weak single approvals,
licensing events and intentions were excluded before prediction.

The cutoff is `2026-04-01`; the validation window is
`[2026-04-01, 2026-07-01)`. All prediction, matching, job-normalization and
acceptance code is frozen before any future-job search.
