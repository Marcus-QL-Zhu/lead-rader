# Strict holdout v10

This is a fresh foreign life-science holdout after the generic role matcher was
changed to use symmetric role-family tags and deterministic maximum one-to-one
matching. A blinded agent selected eight companies from pre-cutoff operating
events without opening or searching any future job page.

The cutoff is `2026-04-01`; the validation window is
`[2026-04-01, 2026-07-01)`. The manifest freezes the accuracy, company support,
coverage and 30-title diversity gates before model execution.
