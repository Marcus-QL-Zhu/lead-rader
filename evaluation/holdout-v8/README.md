# Strict holdout v8

This is a fresh foreign-company regional-hub holdout created after v7 exposed
that product, R&D and commercial hypotheses displaced corporate governance and
enablement roles. Eight new companies were selected by a blinded agent before
future-job search.

The cutoff is `2026-01-01`; the validation window is
`[2026-01-01, 2026-04-01)`. Inputs exclude job ads, workforce clusters,
JOSINT, analyst notes and all post-cutoff information. The manifest also freezes
a 30-title, 10-family and 30-canonical-role diversity gate before prediction.

The first prediction attempt ended on a provider response with no assistant
text before any snapshot was written. The unchanged sealed inputs and code were
retried once; the second attempt produced the frozen snapshot recorded in
`pre-label-seal.json`.
