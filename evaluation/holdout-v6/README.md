# Strict holdout v6

This is a fresh foreign-company confirmation holdout using a different
simulated date after the bilingual role ontology was completed. Candidate
selection was isolated from model predictions and future jobs.

The cutoff is 2026-01-01 and the validation window is
`[2026-01-01, 2026-04-01)`. Inputs exclude job ads, workforce clusters,
JOSINT, analyst notes and post-cutoff information.
